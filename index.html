Week 1
🔌
Basics + Prompting + Connectors
"AI first, judgment always"
Do It

AI is our default — not a supplement to how we used to work. Before you can use Claude well, you need to understand what you're working with: the different features, how connectors plug your tools into Claude, and how to prompt it in a way that produces output you can actually use.

What to explore

Understand Claude features: Chat, Projects, Artifacts, and Claude Code
Set up your environment: response style, preferences, settings
Connect the tools relevant to your work (Drive, Slack, Linear, etc.)
Or, complete the Claude 101 Course — covers this in ~30–45 min
Milestone · Do It
Set at least one preference in Settings. Connect at least two tools. Try a real prompt with one of them.

Skills
"Treat your workflows like a target"
Do ItShare It

A one-off prompt solves today's problem. A Skill solves it every time — consistently, without rebuilding from scratch. Skills work across the entire Claude interface: in chat, with your connected tools, and inside Projects you'll configure next week.

What to explore

What are Skills and how they differ from one-off prompts
Use, Share, and Manage Skills across your workspace
Building a Skill from Scratch
Skill Libraries — finding and reusing what teammates build

Week 3
🗂️
Projects
"Disclose what works. Disclose what breaks."
Do ItShare It

A Project is a persistent workspace where Claude retains context across every conversation — unlike a general chat, which resets when you close it. Configure it once with a system prompt and every conversation in that Project inherits it automatically. Projects can be shared across teams.

What to explore

Creating and configuring a Project — setup, naming, organization
Writing a strong system prompt — the single most important thing you'll do in a Project
Connecting tools and Skills inside a Project (pulling Weeks 1 & 2 together)
Sharing Projects across teams for collaborative ongoing work
Milestone · Do It + Share It
Create a Project for a real work area. Write a system prompt, connect your tools, add the Skill you built last week.
Post to #h1-agentic-ai-accelerator: a snippet of your system prompt + one sentence on what felt different vs. a regular chat

Week 5
🤖
Automation
"Direct what AI executes"
Do ItNominate It

Automation in Claude is a spectrum. Most of you can start today, in chat, with the tools you've already connected. No terminal. No code. No setup beyond Week 1. This week is about removing yourself from the steps that don't need you.

What to explore

What is MCP — the protocol that lets Claude take action, not just answer
Automation Chaining — stringing steps so Claude handles the sequence
Scheduled Tasks — set it up once, let it run
Guardrails — where to keep humans in the loop and why
Milestone · Do It + Nominate It
Set up one automation that runs without you. And nominate a teammate whose work this program was worth copying.
